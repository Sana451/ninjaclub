# Инструкция по админке Ninja Club

## Как попасть в админку

1. Админ — это пользователь с флагом `is_superuser`.
2. Первый админ создаётся автоматически при первом запуске из `.env`:
   `FIRST_SUPERUSER` (email) и `FIRST_SUPERUSER_PASSWORD`. Смените пароль после первого входа.
3. Войдите на сайте через `/login` под этим аккаунтом.
4. В боковом меню появятся разделы админа (ниже). Для обычных клиентов их не видно, а прямые ссылки перенаправляют в `/account`.

Назначить другого админа может только существующий админ: раздел **Пользователи** (`/admin`, из шаблона) → редактирование пользователя → «Суперпользователь».

## Разделы

| Раздел | Путь | Что делает |
|---|---|---|
| Расписание (админ) | `/schedule-admin` | Список занятий на 2 недели, генерация расписания, отмена/возврат занятия, список записанных и отметка «пришёл» |
| Заявки | `/requests` | Заявки с формы на сайте (имя, телефон, взрослые/дети). Отметить «Обработано» |
| Абонементы клиентов | `/user-services` | Абонементы клиентов: выдача, корректировка, активация оплаченных |
| Тренеры | `/trainers-admin` | Добавление и редактирование тренеров (ФИО, фото, описание, показ на сайте) |
| Тренировки | `/trainings-admin` | Виды тренировок (название, уровень, цвет) и недельное расписание (день, время, тренер, лимит мест) |
| Каталог абонементов | `/catalog-admin` | Цены, количество занятий и срок действия абонементов |
| Пользователи | `/admin` | Список пользователей, роли, создание и удаление |

## Расписание

**Сгенерировать расписание.** На `/schedule-admin` нажмите «Сгенерировать на 4 недели». Занятия создаются по недельному расписанию из `/trainings-admin` (в начале заполнено из сида). Уже существующие занятия не дублируются. После изменения недельного расписания сгенерируйте занятия заново.

**Удаление.** Тренеров, тренировки и абонементы каталога не удаляют: снимите галочку «Показывать на сайте» или «Активна» в форме редактирования. Так не теряются старые записи и купленные абонементы.

**Записанные и посещаемость.** Нажмите «Записанные» у занятия. Список показывает клиентов и телефоны. Отметьте галочкой «пришёл» тех, кто действительно был на тренировке. Клиенты из листа ожидания показываются отдельной пометкой, отметить их нельзя.

**Отменить занятие.** Кнопка «Отменить занятие». Занятие исчезает из расписания для клиентов. Кнопка «Вернуть» снова открывает его.

**Вместимость.** Лимит мест задан в занятии (`records_limit`, по умолчанию 12). Когда места заканчиваются, клиенты попадают в лист ожидания и получают место при отмене.

## Абонементы

### Как клиент покупает абонемент

1. Клиент нажимает «Купить абонемент» на странице `/price`. Кнопка пока ведёт в группу ВКонтакте клуба (как на сайте клуба). Покупка в приложении не реализована (заглушка, TODO в коде).
2. Оплата и активация идут вне приложения. Админ может выдать абонемент вручную (см. ниже).

### Как выдать абонемент вручную

1. Войдите админом и откройте `/user-services` («Абонементы клиентов»).
2. Нажмите **«Выдать абонемент»** вверху справа.
3. Выберите абонемент и клиента (клиент должен быть зарегистрирован), при необходимости укажите дату начала (по умолчанию сегодня) и нажмите «Выдать».

Та же кнопка есть под каждой карточкой абонемента на `/price` (для админа).

Абонемент сразу становится активным. Срок и число занятий берутся из каталога.

Также можно использовать API: `POST /api/v1/admin/user-services/` с телом `{"user_id": "<uuid>", "catalog_id": <номер услуги>}`. Документация доступна на `/docs`.

Выданный таким способом абонемент сразу активен: срок и количество занятий берутся из каталога, дата старта — сегодня (или `start_date`, если передана).

### Корректировка абонемента

1. Откройте `/user-services` (пункт «Абонементы клиентов» в меню).
2. В карточке абонемента видны имя и e-mail клиента. Можно изменить:
   - **Осталось занятий** (пустое поле — без лимита);
   - **Действует до**;
   - **Статус** (ожидает оплаты, активен, закрыт, истёк).
3. Нажмите «Сохранить». Изменяются только поля, которые вы трогали на сервере (`PATCH /api/v1/admin/user-services/{id}`).

### Списание занятий

- Занятие списывается автоматически в момент записи клиента на тренировку. Отмена за 2 часа и более до начала возвращает занятие.
- Отметка «пришёл» в расписании **не списывает** занятие, она только фиксирует посещение.
- Ручного списания или корректировки остатка (`visits_left`) в интерфейсе нет.

### Правила записи

- В группу PRO можно записаться так же, как в другие группы, без ограничений по посещениям.
- Абонемент выбирается автоматически: активный, не просроченный, подходящей категории.
- Отмена позже чем за 2 часа не возвращает занятие.

## Справочники (тренеры, тренировки, каталог, персональные слоты)

Отдельных страниц в админке нет. Управление через API `/api/v1/admin/...`:

- `trainers/`, `trainings/`, `weekly-slots/`, `catalog/`, `personal-availability/`
- методы: `GET` (список), `POST` (создать), `PUT /{id}` (изменить), `DELETE /{id}` (удалить).

Для персональных тренировок сначала добавьте доступность тренера (`personal-availability`) и услугу категории `personal` в каталог. В сиде их нет.

## Заявки

Заявки создаются формой «Записаться» на сайте. Откройте `/requests`, позвоните клиенту по ссылке телефона и нажмите «Обработано».
