# Инструкции для Copilot в репозитории

## Правки файлов

- Вносить изменения в файлы только инструментом редактирования (edit/create), чтобы пользователь видел окно подтверждения.
- Не менять файлы через bash-команды, скрипты (python, sed, awk, tee, редирект `>`) и генераторы кода без явного запроса пользователя.
